CH347 驱动安装说明（IMSProg Windows 版）
==========================================

本目录提供 CH347 在 Windows 下使用 IMSProg 所需的驱动与工具。

文件说明
--------
CH341PAR.EXE     沁恒官方一键安装驱动（USB转JTAG/SPI/I2C/GPIO，支持 CH347）
CH341PAR.ZIP     沁恒官方驱动 + DLL 开发库（含 CH347DLL，版本 2.6）
zadig-2.9.exe    WinUSB 驱动安装工具（libusb 设备通用）

重要前提
--------
本 IMSProg 包按 CH347 SPI 设备 PID 0x55de（VID 0x1a86）编译。
IMSProg 通过 libusb 访问编程器，因此 CH347 必须绑定 "WinUSB"
驱动才能被识别。请按下面的方法一操作。

方法一（推荐）：Zadig 安装 WinUSB 驱动
--------------------------------------
1. 先不插编程器。双击运行 zadig-2.9.exe。
2. 菜单 Options -> List All Devices（勾选显示所有设备）。
3. 插入 CH347 编程器（此时系统会枚举为未知设备）。
4. 在下拉列表中选择 CH347 设备，确认界面显示：
   USB ID: 1A86  55DE   （如显示其他 PID，以设备实际枚举为准）
5. 右侧目标驱动选择 "WinUSB"（若列表没有，选 "libusb-win32" 亦可）。
6. 点击 "Install Driver" / "Replace Driver"，等待完成。
7. 重新插拔设备，运行 IMSProg.exe，应能识别 CH347 编程器。

方法二：沁恒官方驱动（仅用于官方工具/串口模式）
-----------------------------------------------
- 双击 CH341PAR.EXE 按向导一键安装；或
- 解压 CH341PAR.ZIP，在设备管理器中手动指定 INF 安装。
注意：官方厂商驱动与 WinUSB 驱动互斥，安装其一后如要用
IMSProg，需用 Zadig 重新替换为 WinUSB（见方法一）。

常见问题
--------
- 设备枚举 PID 不是 55DE？先确认编程器实际 PID，如需改回
  可在 CH347 配置工具中调整；本包固定按 55DE 编译。
- 插上设备无任何反应：检查 USB 线是否数据线、接口是否
  为高速（480Mbps）USB 口。
- 驱动签名提示：沁恒驱动已通过微软数字签名；Zadig 安装
  WinUSB 为系统自带签名驱动，一般无需关闭签名验证。
